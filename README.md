# NeoCity Miner V4.1 — Mobile First

## Purpose
This is a **fresh frontend build** based on the approved mobile visual direction:
- premium dark cyberpunk UI
- NeoCity / Living Mining City identity
- N Coin terminology
- five-tab mobile navigation: Home / Core / Yield / Vault / More
- mobile-first layout
- 8 NeoCity visual assets
- animated/live-feeling telemetry, phase state and ambience layers
- no LightningMiner.com layout or branding is copied

## Important
This package is a visual/frontend baseline. **Supabase is not modified or connected yet.**
Do not add service-role credentials to this repository.

## Main screens
1. Home — hero city core, telemetry, quick actions
2. Core — holographic mining core and control panels
3. Yield — N Coin estimator and reward breakdown
4. Vault — balance, deposit/withdraw and transaction controls
5. More — missions, referrals, shop, leaderboard, settings, help
6. Missions — progression
7. Network — skyline, energy grid, vehicles, ambience

## Responsive strategy
- Phone: primary design target
- Tablet: 700px+
- Desktop: 1024px+
- Wide desktop: fluid content up to 1200px

## Safe deployment order
1. Create empty GitHub repository.
2. Upload this folder contents.
3. Deploy to Vercel as a new frontend project.
4. Verify mobile UI.
5. Only after visual approval, connect the existing Supabase project.
