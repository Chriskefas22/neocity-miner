# NeoCity Miner V4.2

Fresh visual-first rebuild based on the supplied mobile blueprint.

## Design direction
NeoCity is a **Living Mining City**:
- premium dark sci-fi/cyberpunk visual system
- mobile-first
- animated city atmosphere
- modular city/core/yield/reserve/network views
- N Coin terminology
- no LightningMiner page/layout dependency

## Scope
This release focuses on:
- visual design
- graphics
- animation
- responsive behavior
- UI navigation

Backend/Supabase integration is intentionally deferred.

## Important economy terminology
Currency: **N Coin**

Final production economy, reward caps, levels, exchange rules, contests, bounties, withdrawals, PTC, shortlinks, offers, and anti-abuse rules must be enforced server-side when backend integration is added.

## Safety boundary
Never put Supabase service-role credentials into frontend files.
